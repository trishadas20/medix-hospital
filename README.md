# Medix Hospital Admin

Modern responsive hospital administration dashboard built with React, Vite, React Router, and Lucide icons.

## Modules
- Dashboard
- Doctors
- Patients
- Appointments
- Billing
- Pharmacy
- Lab Reports

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

All records currently use demo data from `src/data/mockData.js`. Replace this file or connect the pages to your API/backend.
